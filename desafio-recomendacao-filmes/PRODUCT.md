# Product

## Register

product

## Users

Engineers and interviewers reviewing a portfolio project. They evaluate technical craft and design taste alongside the ML/AI implementation. Secondary: any curious person who encounters the demo and tries it out.

## Product Purpose

AI-powered movie recommendation app backed by a neural collaborative-filtering model. Users select a profile, like movies, and receive personalized recommendations. The ML training pipeline is visible (users can trigger training and watch epoch-by-epoch progress). Success: the reviewer walks away impressed by both the engineering and the visual execution.

## Brand Personality

Cinematic, editorial, confident. Feels closer to A24 or Criterion than to a Netflix clone — deliberately artistic, slightly moody, film-literate. The dark palette is intentional, not default. Three words: cinematic, precise, atmospheric.

## Anti-references

- **Generic Netflix clone**: same red primary, same card grid, same hero gradient. The project currently skews too close. Must diverge in typography and card craft.
- **SaaS dashboard dark mode**: slate grays, metric cards, "Enterprise" energy. Wrong register entirely.
- **Gradient-text hero sections**: banned. Typography carries weight through scale and weight contrast, not gimmicks.

## Design Principles

1. **The gradient is a design decision, not a fallback.** Without poster images, the genre-color system must be rich, varied, and deliberately composed — not a uniform orange wash.
2. **Typography does the heavy lifting.** Cinematic = bold hierarchy, generous spacing, confident scale. Not more UI chrome.
3. **Reveal the intelligence.** The AI angle is a feature, not a footnote. The recommendation row and model status should feel meaningful, not bolted-on.
4. **Portfolio-grade finish.** Every hover state, transition, and edge case must be production-quality. An interviewer will hover everything.

## Accessibility & Inclusion

WCAG AA minimum. Reduced-motion media query on all transitions. Sufficient contrast for muted text on dark backgrounds.
